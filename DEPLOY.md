# ТЗ: развёртывание дэков на поддомены membria.ai

Репозиторий: `sitesynth/membria-pitchdecks`, ветка `main`.
Дата: 4 августа 2026.

---

## 1. Целевое состояние

| Поддомен | Папка в репозитории | Что это |
| --- | --- | --- |
| `deck.membria.ai` | `deck/` | Основной инвестиционный дэк, 17 слайдов |
| `deck-short.membria.ai` | `deck-short/` | Короткая версия, 10 слайдов, под pre-seed в Люксембурге |

Точка входа везде — `index.html` в корне папки.

Действий в коде не требуется. Всё, что осталось — конфигурация хостинга и DNS.

## 3. Шаг 0 — определить текущий хостинг

Сейчас `deck.membria.ai` отдаёт файл `membria-deck.html` из **корня** репозитория, а не `index.html`. Это нестандартное поведение: значит, где-то настроено правило перезаписи или указан нестандартный входной файл.

Нужно выяснить, где это настроено. Проверить по порядку:

1. Кабинет **Cloudflare** → Workers & Pages → есть ли проект, привязанный к этому репозиторию
2. Кабинет **Netlify** или **Vercel** → список сайтов
3. Настройки репозитория на GitHub → Settings → Pages
4. DNS-записи домена `membria.ai`: куда указывает `CNAME` для `deck` — это назовёт провайдера

Дальше выполняется один из разделов ниже.

---

## 4. Вариант A — Cloudflare Pages (наиболее вероятный)

GitHub Pages не умеет отдавать произвольный файл вместо `index.html`, поэтому текущая конфигурация почти наверняка на Cloudflare.

Для каждого из четырёх поддоменов создаётся **отдельный проект Pages**, все смотрят в один репозиторий, отличаются только корневой директорией.

### Создание проекта

Workers & Pages → Create → Pages → Connect to Git → выбрать `sitesynth/membria-pitchdecks`.

Настройки сборки:

| Параметр | Значение |
| --- | --- |
| Production branch | `main` |
| Framework preset | None |
| Build command | оставить пустым |
| Build output directory | `deck` (или `deck-short`, `onepager`, `deck3`) |

Повторить четыре раза, меняя только output directory и имя проекта.

### Привязка домена

В каждом проекте: Custom domains → Set up a custom domain → ввести нужный поддомен. Cloudflare сам создаст `CNAME`, если зона `membria.ai` обслуживается им же.

### Переключение существующего deck.membria.ai

Домен нельзя привязать к двум проектам одновременно. Порядок:

1. Создать новый проект с output directory `deck`
2. Дождаться успешного деплоя и проверить его по временному адресу `*.pages.dev`
3. В **старом** проекте отвязать `deck.membria.ai` (Custom domains → Remove)
4. В **новом** проекте привязать `deck.membria.ai`
5. Старый проект удалить или оставить отключённым как резерв

## 5. Вариант B — GitHub Pages

**Ограничение:** GitHub Pages даёт один сайт и один кастомный домен на репозиторий. Четыре поддомена из одного репозитория так не сделать.

Три обхода:

**Б1. Один домен, четыре пути.** Settings → Pages → Source: Deploy from a branch → `main` / `root`. Тогда адреса будут:

```
deck.membria.ai/deck/
deck.membria.ai/deck-short/
deck.membria.ai/onepager/
deck.membria.ai/deck3/
```

Плюс: настраивается за минуту. Минус: адреса некрасивые, инвестору такую ссылку слать хуже.

**Б2. Четыре репозитория.** Разнести папки по отдельным репозиториям, у каждого свой Pages и свой домен. Плюс: чистые адреса. Минус: правки надо разносить по четырём местам, история расползается.

**Б3. Переехать на Cloudflare Pages** — см. вариант A. Рекомендуемый путь, если нужны чистые поддомены.

При любом варианте с GitHub Pages в корень репозитория нужно добавить файл `.nojekyll` (пустой), иначе Jekyll может проглотить папки и файлы, начинающиеся с подчёркивания.

## 6. Вариант C — Netlify или Vercel

Логика та же, что у Cloudflare: четыре отдельных сайта из одного репозитория.

**Netlify:** Add new site → Import an existing project → выбрать репозиторий → Base directory: `deck`, Build command: пусто, Publish directory: `deck`. Домен: Domain settings → Add custom domain.

**Vercel:** Add New → Project → импорт репозитория → Root Directory: `deck` → Framework Preset: Other → Build Command: пусто, Output Directory: оставить по умолчанию. Домен: Settings → Domains.

## 7. DNS

Если зона `membria.ai` в Cloudflare и хостинг тоже Cloudflare Pages — записи создаются автоматически при привязке домена, вручную ничего делать не нужно.

Если хостинг внешний, добавить три записи:

| Тип | Имя | Значение |
| --- | --- | --- |
| CNAME | `deck-short` | адрес, выданный хостингом |
| CNAME | `onepager` | адрес, выданный хостингом |
| CNAME | `deck3` | адрес, выданный хостингом |

Запись `deck` уже существует — при смене хостинга её значение нужно обновить.

TTL можно оставить автоматическим. Распространение занимает от минуты до часа.

## 8. Что делать со старым membria-deck.html

Файл `membria-deck.html` лежит в корне репозитория и прямо сейчас держит `deck.membria.ai`. Удалять его **до** переключения хостинга нельзя — домен ляжет.

Порядок:

1. Новый деплой из папки `deck/` заработал и проверен
2. `deck.membria.ai` переключён на него
3. Только после этого удалить из корня: `membria-deck.html` и ассеты, которые использовались только им

Осторожно: в корне лежат и другие дэки — `bankos-deck.html`, `infra.html`, `strategy.html`, `index000.html`. Они делят с основным дэком общие шрифты и изображения. Перед удалением любого ассета проверить, не ссылается ли на него что-то ещё:

```
grep -rl "имя-файла" --include="*.html" .
```

Если сомнения есть — не удалять. Пара мегабайт в репозитории дешевле сломанной страницы.

## 9. Чек-лист приёмки

По каждому из четырёх адресов проверить:

- [ ] Страница открывается по HTTPS, сертификат валиден
- [ ] Шрифты подгрузились: заголовки набраны засечным DM Serif Display, а не системным шрифтом
- [ ] Изображения на месте: фото команды, логотип, иконки на слайдах
- [ ] Навигация работает: стрелки клавиатуры, точки справа, скролл со снапом
- [ ] Кнопка PDF на обложке скачивает файл, а не открывает 404
- [ ] Ссылка, отправленная в Telegram или Slack, разворачивается в превью с логотипом Membria
- [ ] На мобильном в портретной ориентации показывается подсказка повернуть экран
- [ ] `deck3.membria.ai` отдаёт **старую** версию, `deck.membria.ai` — новую (не перепутаны местами)

Отдельно для онепейджера:

- [ ] Умещается в один экран без прокрутки на 16:9
- [ ] Кнопка PDF в правом верхнем углу видна и скачивает A4 landscape
- [ ] При печати из браузера (Cmd+P) кнопка PDF со страницы исчезает

## 10. Как пересобирать PDF после правок

PDF не генерируются автоматически. После изменения любого `index.html` соответствующий PDF устареет и будет отдавать инвестору неактуальную версию.

Пересборка вручную: открыть страницу в Chrome → Cmd+P → Destination: Save as PDF → Layout: Landscape → Margins: None → включить Background graphics.

Параметры страницы уже заданы в CSS через `@page`, поэтому размер подставится сам: 1280×720 для дэков, A4 landscape для онепейджера.

Файлы сохранять строго под теми же именами, иначе кнопки скачивания перестанут работать:

- `deck/membria-deck.pdf`
- `deck-short/membria-deck.pdf`
- `onepager/membria-onepager.pdf`

## 11. Итоговый порядок работ

1. Определить текущий хостинг (раздел 3)
2. Создать проекты и привязать три новых поддомена (раздел 4, 5 или 6)
3. Проверить новые адреса по чек-листу (раздел 9)
4. Переключить `deck.membria.ai` на папку `deck/` (раздел 4, последний пункт)
5. Убедиться, что старый адрес отдаёт новую версию
6. Через несколько дней стабильной работы — прибраться в корне репозитория (раздел 8)
