02
Context

What
Membria Is

A cloud memory service for AI coding assistants (Claude Code / Codex). It remembers everything the AI learned yesterday — so clients get an assistant that gets smarter with use, with nothing to install.
Currently: single GCP VM, prototype stage. This brief covers what's needed to reach commercial scale with Luxembourg AI Factory.
1.
Memory That Learns From Mistakes
Every decision the AI agent makes is recorded in a knowledge graph, together with how it turned out. When something fails, the failure is remembered — and the agent never repeats it. That memory is the product.
2.
Three SaaS Verticals
Engineering (industrial standards and design rules) and Accounting (regulatory requirements) serve B2B teams. Code is also sold as a solo subscription — an add-on to Claude Code and similar assistants for individual developers. Each client's data is private; shared industry knowledge benefits everyone.
3.
Speed Is a Hard Requirement
The AI assistant checks Membria's memory before every step it takes — hundreds of times per working day, per user. Each check must return in under 200 ms, or every user feels the slowdown directly.
4.
Background Knowledge Processing
Behind the scenes, Membria reviews the AI's work, reads documents, and turns raw experience into reusable knowledge. Today this runs on rented third-party AI services with usage limits — our own inference servers remove that ceiling.
